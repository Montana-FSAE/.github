# Montana FSAE 🏁

Formula SAE team at **Montana State University** in Bozeman, MT. We design, build, and race a formula-style car every season.

This org holds the team's software, firmware, hardware, and data tooling.

## Subteams

| Subteam | What lives here |
|---|---|
| Electrical / DAQ | CAN bus (DBC files, generated C), sensor nodes, PDM, data logger, dash |
| Powertrain | ECU tune/config, engine and fuel system data |
| Chassis / Suspension | Analysis scripts, setup sheets, sim |
| Aero | CFD setups, post-processing |
| Business / Ops | Sponsor docs, scheduling, internal tools |

## Repo naming

`<subteam>-<project>` in lowercase-kebab-case, e.g. `elec-pdm-firmware`, `elec-can-dbc`, `pt-ecu-tune`, `sus-kinematics`, `aero-cfd-scripts`.

Prefixes: `elec`, `pt`, `sus`, `chassis`, `aero`, `bus`, `team` (cross-team).

## Getting started

1. Get added to the org by a lead (send your GitHub username).
2. Read [CONTRIBUTING](https://github.com/Montana-FSAE/.github/blob/main/CONTRIBUTING.md).
3. Create repos for your projects — new repos are **private** by default; ask a lead to make one public.

We're a small-budget team and rely on our sponsors. Interested in supporting us? Reach out to the team leads.
